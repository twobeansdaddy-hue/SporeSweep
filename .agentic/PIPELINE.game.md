# 게임 프로젝트 추가 절차 (game 프로필)

이 프로젝트는 게임이다. `PIPELINE.md`의 단계에 아래를 더한다.
승인 지점과 금지 규칙은 `PIPELINE.md`·`AGENTS.md`가 기준이고, 이 문서는 새 승인 지점을 만들지 않는다.
기획서·진행 상태 문서·실행 명령의 위치는 AGENTS.md "프로젝트" 절에 적혀 있다 (기본: `docs/PLAN.md`, `docs/STATUS.md`).

## 기획서가 기준이다
- 규칙·수치·화면·단계의 기준은 기획서다. 요청이 기획서와 다르거나 기획서에 없는 규칙을 정해야 하면
  코드를 먼저 바꾸지 않는다. 기획서를 어떻게 고칠지 보여 주고 확인을 받는다 (승인 지점 1: 요구사항이 모호할 때).
- 확인을 받으면 기획서와 코드를 같은 변경에서 고친다. 기획서에 적을 만큼 크지 않은 구현 결정은 진행 상태 문서에 적는다.

## 1단계에 더하는 것: 무엇을 바꾸는 요청인가
`--state`에 아래 분류를 함께 적고, 분류에 맞는 확인을 뒤 단계에서 한다.

| 분류 | 예 | 꼭 하는 확인 |
|---|---|---|
| 규칙 | 판정, 이동, 전투, 진행 저장 | 테스트 (같은 입력·같은 시드면 같은 결과) |
| 수치 | 속도, 가격, 확률, 보상, 난이도 | 조정 값 파일에서만 바꾼다. 이전 값 → 새 값과 이유를 보고한다 |
| 화면·조작·연출 | 화면 배치, 입력, 카메라, 효과, 소리 | 4-1단계 실행 확인 |
| 콘텐츠 | 맵, 레벨, 대사, 아이템 목록 | 데이터 검증(있으면)과 4-1단계 실행 확인 |
| 에셋 | 그림, 소리, 글꼴 | 출처·라이선스 기록, 4-1단계 실행 확인 |
| 플랫폼 | 결제, 광고, 순위표, 저장 위치, 스토어 | 5단계 고위험 확인 |

## 4단계에 더하는 것
- 돈이 드는 생성(음성·음악·이미지 생성 API 등)은 실행 전에 무엇을 몇 번 만들지 알리고 승인을 받는다 (승인 지점 4와 같이 다룬다).
- 에셋을 새로 만들거나 들여오면 출처, 라이선스, 만든 방법(도구·명령)을 프로젝트의 에셋 기록 문서에 적는다. 문서가 없으면 진행 상태 문서에 적는다.
- 프로젝트의 경고 검사 명령이 있으면 테스트와 함께 돌리고 경고 0을 지킨다.

### 4-1. 실행 확인 (분류가 화면·조작·연출, 콘텐츠, 에셋, 수치일 때)
테스트 통과만으로 끝내지 않는다. 게임을 실제로 띄워 바뀐 곳을 본다.
- AGENTS.md "프로젝트" 절의 실행·촬영 명령으로 띄우고, 바뀐 화면을 스크린샷으로 남겨 직접 확인한다
  (글자가 잘리거나 겹치지 않는지, 화면 밖으로 나가지 않는지, 멈추지 않는지).
- 수치를 바꿨으면 프로젝트의 균형 측정·시뮬레이션 명령이 있을 때 다시 돌리고 바뀐 값을 본다.
- 띄울 수 없으면(기기·엔진 없음, 헤드리스에서 안 뜸) 지어내지 않는다. "실행 확인 못 함"과 이유를 8단계 보고에 적는다.
- 네가 띄워 본 것은 사람의 플레이가 아니다. 조작감·재미·난이도는 "사람이 아직 플레이하지 않음"으로 남긴다.

## 5단계에 더하는 것: 판정과 상관없이 승인을 받는 변경
- 저장 데이터 형식을 바꿔 기존 저장을 못 읽거나 다르게 읽게 되는 변경
- 실제 돈이 오가는 것: 인앱 결제, 가격, 광고 보상, 유료 재화의 확률·지급량
- 스토어에 올라가는 것: 빌드 업로드, 스토어 문구·이미지, 연령 등급 관련 내용

## 7단계에 더하는 것
완료 게이트와 함께 실행 확인 판정을 받는다.
```
node tools/agentic/decide.mjs play-check --state "<변경 요약 + 실행 확인 방법과 결과 + 사람 플레이 여부>"
```
- `verdict.run_missing`이 참이면(플레이어가 보는 것이 바뀌었는데 실행 확인 근거가 없음) 4-1단계를 하거나, 못 한 이유와 함께 미확인으로 보고한다.
- `fallback: true`이거나 `uncertain`이면 네가 직접 판단한다.

## 8단계 보고에 더하는 것
- 실행 확인: 쓴 명령과 스크린샷 경로, 또는 "실행 확인 못 함"과 이유
- 사람 플레이: 했으면 누가·무엇을, 아니면 "사람이 아직 플레이하지 않음"
- 실기기: 시뮬레이터·에뮬레이터·데스크톱에서만 봤으면 "실기기 미확인"
- 바꾼 수치: 이전 값 → 새 값
